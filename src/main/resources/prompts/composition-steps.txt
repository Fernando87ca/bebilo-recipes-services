ESTILO PASO A PASO CONCISO
Devuelve instructions.type=steps y una lista steps no vacía. Cada bloque representa un proceso culinario, con objective obligatorio como objetivo breve y tasks como lista ordenada de acciones concretas y escuetas. No incluyas números, viñetas ni Markdown en las cadenas: la app numera cada lista desde 1. No uses text ni title.
Evita introducciones, explicaciones narrativas y repeticiones para ahorrar tokens. Conserva cantidades, tiempos, tamaños, textura y señales de finalización necesarios para cocinar de forma segura. No sacrifiques indicaciones necesarias para los bebés por brevedad. Una acción por tarea; agrupa acciones relacionadas bajo el mismo objetivo. La imagen opcional se asociará al ID del bloque y se mostrará tras todas sus tareas. durationMinutes es opcional y representa el bloque completo.
